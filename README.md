# 바닐라 웹 기초 다지기

## 진행 규칙
1. `예시.html` 을 브라우저로 열어보고, 코드를 읽는다 (주석이 선생님)
2. `도전.html` 을 **직접** 채운다. 예시를 그대로 복붙 금지, 보고 나서 덮고 쓰기
3. 다 하면 "1단계 다 했어" 라고 말한다 → 채점 + 피드백
4. 통과하면 같은 화면에 JS를 붙여서 동적으로 만든다
5. 다음 단계로

## 단계
| 단계 | 주제 | 만드는 것 |
|---|---|---|
| 01 | HTML 문서 구조 / 기본 태그 | 프로필 카드 페이지 |
| 02 | CSS 기초 (선택자, 색, 폰트, 박스모델) | 카드 꾸미기 |
| 03 | 레이아웃 (flex) | 가로 3칸 카드 목록 |
| 04 | 레이아웃 (grid) + 반응형 | 갤러리 |
| 05 | 폼 요소 / 시맨틱 태그 | 회원가입 화면 |
| 06 | JS 기초: 변수, 타입, 함수 | 콘솔 연습 |
| 07 | DOM 선택 & 조작 | 버튼 누르면 글자 바뀜 |
| 08 | 이벤트 (click, input, submit) | 카운터 / 실시간 입력 |
| 09 | 배열 메서드 + 반복 렌더링 | 할 일 목록 (Todo) |
| 10 | 폼 검증 + localStorage | 저장되는 Todo |
| 11 | 비동기 (fetch, async/await) | API에서 데이터 가져와 그리기 |
| 12 | 종합 프로젝트 | 검색+필터되는 카드 앱 |
