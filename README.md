# 바닐라 웹 기초 다지기

**목표** : HTML, CSS로 기본적인 틀을 만들고 JS를 붙여 간단한 동적 웹을 만들어본다.

## 진행 규칙
1. `예시.html` 을 브라우저로 열어보고, 코드를 읽는다 (주석이 선생님)
2. 같은 걸 `index.html` 에 **직접** 만든다. 복붙 금지
3. 다 하면 "됐음" → 채점 + 피드백
4. 통과하면 다음 단계

결과물은 전부 루트의 `index.html` 하나에 누적됩니다 — **"내가 좋아하는 영화" 카드 앱**.
질문/답변 정리는 [QNA.md](QNA.md).

## 단계

| 단계 | 주제 | 만든 것 | 상태 |
|---|---|---|---|
| 01 | HTML 문서 구조 / 기본 태그 | 영화 소개 페이지 | ✅ |
| 02 | CSS 기초 (선택자, 박스모델) | 카드 꾸미기 | ✅ |
| 03 | 레이아웃 (flex) | 알약 태그 목록, 입력창+버튼 한 줄 | ✅ |
| 04 | DOM 선택 & 조작 + 이벤트 | 한줄평 등록 버튼 | ✅ |
| 05 | 배열 상태 → render() 구조 | 한줄평 목록, 삭제, 개수 | ✅ |
| 06 | localStorage | 새로고침해도 유지되는 한줄평 | ✅ |
| 07 | 비동기 (fetch, async/await) | API에서 한줄평 불러오기 | ✅ |
| 08 | 레이아웃 (grid) | 영화 카드 갤러리 | ✅ |
| 09 | 반응형 (`@media`) | 화면 크기별 레이아웃 | ⬜ |
| 10 | 검색 (`input` 이벤트 + `filter`) | 영화 제목 실시간 검색 | ⬜ |
| 11 | 필터 + 정렬 (`change`, `sort`, `map`) | 장르 필터 / 연도·제목 정렬 | ⬜ |
| 12 | 폼 + 검증 + 시맨틱 태그 | 영화 추가 폼, 에러 메시지 | ⬜ |
| 13 | JS 기초 보강 | 타입, 연산자, 조건문, 반복문 | ⬜ |
| 14 | 코드 분리 + 마무리 | `style.css` / `app.js` 로 분리 | ⬜ |
